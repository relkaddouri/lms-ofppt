Les jointures SQL

Samira Lahlou · lecture ≈ 8 min
Introduction

Une base relationnelle répartit l'information dans plusieurs tables pour éviter la redondance. La jointure est l'opération qui permet de rassembler ces données au moment de l'interrogation, sans jamais les dupliquer physiquement.

Notions
Jointure interne

Ne conserve que les lignes ayant une correspondance dans les deux tables. C'est le comportement par défaut de JOIN.

Jointure externe

Conserve toutes les lignes d'un côté, même sans correspondance : les colonnes de l'autre table prennent alors la valeur nulle.

Condition de jointure

Elle s'écrit après ON et met en relation une clé étrangère avec une clé primaire.

Exemples 
SELECT s.nom, m.libelle
FROM stagiaire s
JOIN inscription i
  ON i.id_stagiaire = s.id
JOIN module m
  ON m.id = i.id_module
WHERE m.code = 'M106';

Deux jointures successives relient stagiaires et modules par la table d'association. Le filtre porte sur la table de destination, pas sur la condition de jointure.

À retenir
Une jointure oubliée produit un produit cartésien. ON relie, WHERE filtre après la jointure. Toujours préfixer les colonnes par l'alias de table.
